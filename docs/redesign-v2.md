# V2: AI-first coworking

## Why

The first version made Wi-Fi the punchline and felt too conservative. The product is a physical coworking space with free AI credits. Put that offer first, use a younger visual direction and publish an actual GitHub Pages preview.

## Scope

- Hero: Coworking. With free AI credits. Wi-Fi moves to the amenities list.
- Contemporary sans-serif typography, lime and lilac accents, lively architectural concept imagery, restrained motion with a pause control and reduced-motion support.
- Preserve the tested enquiry and consent flows. No false live venue, inventory, sponsor or model-allocation claims.
- Verify 4K and real mobile emulation, then publish the current review branch to GitHub Pages and test the real public URL.
